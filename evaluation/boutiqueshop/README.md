# BoutiqueShop

This directory contains the deployment artifacts of the
Google Cloud Online Boutique microservices application.

## Source Application
Google Cloud Online Boutique

Repository:
https://github.com/GoogleCloudPlatform/microservices-demo

## Directory Contents
- `boutiqueshop_actual.xml`: Generated EA in ArchiMate Exchange Format
- `boutiqueshop_actual.yaml`: Source EDMM model used in the transformation
- `boutiqueshop_expected.xml`: Expected full Ground truth model in ArchiMate Exchange Format 
- `boutiqueshop_expected-wbl.xml`: Expected scoped Ground truth model in ArchiMate Exchange Format 
- `boutiqueshop-expected.archimate`: Expected full Ground truth model  ArchiMate modeling project
- `boutiqueshop-expected-wbl.archimate`: Expected scoped Ground truth model  ArchiMate modeling project
