# OTEL-Shop-Ansible

This directory contains the deployment artifacts of the
OpenTelemetry Demo microservices application using Ansible.

## Source Application
OpenTelemetry Demo

Repository:
https://github.com/open-telemetry/opentelemetry-demo

## Directory Contents
- `OTEL-Ansible__actual.xml`: Generated EA in ArchiMate Exchange Format
- `OTEL-Ansible_actual.yaml`: Source EDMM model used in the transformation
- `OTEL-Ansible_expected.xml`: Expected full Ground truth model in ArchiMate Exchange Format
- `OTEL-Ansible_expected-wbl.xml`: Expected scoped Ground truth model in ArchiMate Exchange Format
- `OTEL-Ansible-expected.archimate`: Expected full Ground truth model ArchiMate modeling project
- `OTEL-Ansible-expected-wbl.archimate`: Expected scoped Ground truth model ArchiMate modeling project
