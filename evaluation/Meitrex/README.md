# Meitrex

This directory contains the deployment artifacts of the Meitrex platform used for evaluation.

## Source Application
Google Cloud Online Boutique

Repository:
https://github.com/MEITREX/infrastructure/tree/6fd6023e78e2f031241c2fdd21a2f87e0d5d85e9

## Directory Contents
- `meitrex_actual.xml`: Generated EA in ArchiMate Exchange Format
- `meitrex_actual.yaml`: Source EDMM model used in the transformation
- `meitrex_expected.xml`: Expected full Ground truth model in ArchiMate Exchange Format 
- `meitrex_expected-wbl.xml`: Expected scoped Ground truth model in ArchiMate Exchange Format 
- `meitrex-expected-wbl.archimate`: Expected full Ground truth model  ArchiMate modeling project
- `meitrex-expected-wbl.archimate`: Expected scoped Ground truth model  ArchiMate modeling project
