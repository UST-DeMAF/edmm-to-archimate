# OTEL-Shop-Kubernetes

This directory contains the deployment artifacts of the
OpenTelemetry Demo microservices application using Kubernetes.

## Source Application
OpenTelemetry Demo

Repository:
https://github.com/open-telemetry/opentelemetry-demo

## Directory Contents
- `OTEL-kubernetes_actual.xml`: Generated EA in ArchiMate Exchange Format
- `OTEL-kubernetes_actual.yaml`: Source EDMM model used in the transformation
- `OTEL-kubernetes_expected.xml`: Expected full Ground truth model in ArchiMate Exchange Format
- `OTEL-kubernetes_expected-wbl.xml`: Expected scoped Ground truth model in ArchiMate Exchange Format
- `OTEL-Kubernetes-expected.archimate`: Expected full Ground truth model ArchiMate modeling project
- `OTEL-Kubernetes-expected-wbl.archimate`: Expected scoped Ground truth model ArchiMate modeling project
