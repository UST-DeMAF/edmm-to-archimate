# T2Store-Modulith

This directory contains the deployment artifacts of the
T2Store modulith application.

## Source Application
T2Store-Modulith

Repository:
https://t2-documentation.readthedocs.io/en/latest/

## Directory Contents
- `T2Store-modulith_actual.xml`: Generated EA in ArchiMate Exchange Format
- `T2Store-modulith_actual.yaml`: Source EDMM model used in the transformation
- `T2Store-modulith_expected.xml`: Expected full Ground truth model in ArchiMate Exchange Format
- `T2Store-modulith_expected-wbl.xml`: Expected scoped Ground truth model in ArchiMate Exchange Format
- `T2Store-modulith-expected.archimate`: Expected full Ground truth model ArchiMate modeling project
- `T2Store-modulith-expected-wbl.archimate`: Expected scoped Ground truth model ArchiMate modeling project
