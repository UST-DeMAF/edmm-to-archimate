# T2Store-Microservices

This directory contains the deployment artifacts of the
T2Store microservices application.

## Source Application
T2Store-Microservices

Repository:
https://t2-documentation.readthedocs.io/en/latest/

## Directory Contents
- `T2Store-microservices_actual.xml`: Generated EA in ArchiMate Exchange Format
- `T2Store-microservices_actual.yaml`: Source EDMM model used in the transformation
- `T2Store-microservices_expected.xml`: Expected full Ground truth model in ArchiMate Exchange Format
- `T2Store-microservices_expected-wbl.xml`: Expected scoped Ground truth model in ArchiMate Exchange Format
- `T2Store-microservices-expected.archimate`: Expected full Ground truth model ArchiMate modeling project
- `T2Store-microservices-expected-wbl.archimate`: Expected scoped Ground truth model ArchiMate modeling project
