# OTEL-Shop-Terraform

This directory contains the deployment artifacts of the
OpenTelemetry Demo microservices application using Terraform.

## Source Application
OpenTelemetry Demo

Repository:
https://github.com/open-telemetry/opentelemetry-demo

## Directory Contents
- `OTEL-Terraform_actual.xml`: Generated EA in ArchiMate Exchange Format
- `OTEL-Terraform_actual.archimate`: Generated EA ArchiMate modeling project
- `OTEL-Terraform_actual.yaml`: Source EDMM model used in the transformation
- `OTEL-Terraform_expected.xml`: Expected full Ground truth model in ArchiMate Exchange Format
- `OTEL-Terraform_expected-wbl.xml`: Expected scoped Ground truth model in ArchiMate Exchange Format
- `OTEL-Terraform_expected-wbl.archimate`: Expected scoped Ground truth model ArchiMate modeling project
